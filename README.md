Evaluacion2 - Rutas con GraphHopper

Programa en Python que consulta la API de GraphHopper (geocodificacion y rutas) para planificar un viaje.
Todo el texto de interaccion y las instrucciones paso a paso del viaje estan en espanol, y las distancias
se muestran con un maximo de dos decimales.

Requisitos
- Python 3
- Libreria requests (pip install requests)
- Una clave (API key) de GraphHopper

Como ejecutarlo
1. Abra graphhopper_es.py y reemplace la clave de la variable key por su clave de GraphHopper.
2. Ejecute: python3 graphhopper_es.py
3. Ingrese la ubicacion de inicio y el destino.
4. Para salir, escriba s o salir.
